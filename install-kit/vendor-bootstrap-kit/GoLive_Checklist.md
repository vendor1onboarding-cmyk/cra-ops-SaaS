# Go-Live Checklist

Use this checklist to confirm a vendor instance is ready for production.

## Database

- Install scripts applied in order
- Schema verification completed
- Indexes, functions, triggers, and views present
- Row-level security confirmed

## Application

- Vercel deployment completed
- Environment variables set correctly
- Login and password reset tested
- Dashboard loads successfully
- Admin workflows validated

## Operations

- Seed data loaded
- Backup completed before launch
- Support contacts confirmed
- Go-live approval recorded
- Rollback path documented

## Branding

- Vendor name confirmed
- Logo and favicon configured
- Theme colors reviewed
- Printed documents validated
