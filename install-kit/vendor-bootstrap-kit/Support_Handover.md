# Support Handover

This document captures the post-launch ownership transfer for a vendor.

## Handover Items

- Production URL
- Supabase project reference
- Deployment version
- Backup location
- Release notes
- Admin contact list
- Escalation contact list

## Support Expectations

- Response time for operational incidents
- Backup and restore ownership
- Upgrade approval workflow
- Branding update process
- User onboarding and offboarding process

## Acceptance

The vendor is considered handed over when:

1. The environment is live.
2. The support team has access to the required references.
3. The rollback and backup process is documented.
4. The vendor accepts operational ownership.
