# Vendor Bootstrap Kit

This kit packages the first-run materials needed to onboard a new vendor onto
CRA OPS using a separate Supabase project and the shared application codebase.

## Purpose

The bootstrap kit is the operational handoff package for a new vendor. It
collects the vendor inputs, readiness checks, launch steps, and support notes
in one place so rollout can happen consistently across tenants.

## Contents

- `Vendor_Profile_Template.md` - the intake template for vendor-specific details
- `Environment_Matrix.md` - environment and secret mapping
- `GoLive_Checklist.md` - launch readiness checklist
- `Support_Handover.md` - post-launch handover and ownership notes

## How to Use

1. Fill in the vendor profile template.
2. Map Supabase and Vercel values in the environment matrix.
3. Complete the go-live checklist before production release.
4. Use the handover document to transfer support responsibilities cleanly.
