# Install Kit

This directory contains the commercial deployment framework for CRA OPS.

It is intended to support multi-vendor rollout with separate Supabase projects
while keeping the application codebase shared and unchanged.

## Contents

- `database/` - database packaging and versioning notes
- `deployment/` - deployment runbooks and environment steps
- `configuration/` - tenant and environment configuration guidance
- `branding/` - vendor branding and white-label assets guidance
- `templates/` - reusable onboarding and deployment templates
- `docs/` - vendor-facing operational documentation

## Usage

Use these documents and templates when preparing a new vendor environment,
setting up a Supabase project, or planning a version upgrade.
