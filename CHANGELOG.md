# CRA OPS Changelog

This changelog records product and platform releases for CRA OPS using semantic
versioning.

## Versioning Model

- Application version: `MAJOR.MINOR.PATCH`
- Database version: `MAJOR.MINOR.PATCH`
- Release tags follow the product label format: `CRA OPS vMAJOR.MINOR.PATCH`
- Current version: `CRA OPS v1.0.0`
